 # RenderLite Changelog

# v1.3.1
* Settings are now grouped: performance settings first, other settings below

# v1.3.0
* Settings that need a restart now show a Restart button
* Maximum Render FPS and Game logic FPS is now 480
* Dark window title bar now also works with borderless windows
* Anti-crash is now off by default
* Added this changelog

# v1.2.0
* Added Draw divide: draws the picture at a lower frame rate than the game logic
* Added a hotkey to switch Draw divide on and off
* Added Game logic FPS and Render FPS settings
* Added a dark window title bar

# v1.1.0
* Added power plan, background apps and focus mode
* Added GPU preference
* Added fast loading
* Added experimental anti-crash

# v1.0.0
* Initial release
* Process priority, power throttling and timer resolution
